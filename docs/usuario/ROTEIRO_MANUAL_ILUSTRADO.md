# Roteiro para Manual Ilustrado do CAIGE

## Objetivo
Este documento serve como base para criar um **manual em imagem/PDF ilustrado**, com prints das telas e instruções curtas de uso.

A ideia é transformar o conteúdo operacional do sistema em páginas visuais, fáceis de entender por professores, supervisores e outros usuários.

---

## Padrão recomendado para cada página do manual
Cada tela do manual ilustrado deve seguir o mesmo modelo:

### Estrutura visual sugerida
1. **Título da tela**
2. **Objetivo da tela**
3. **Print da tela com destaques numerados**
4. **Legenda explicando cada número**
5. **Passo a passo resumido**
6. **Dica ou observação importante**

### Modelo textual
```text
TÍTULO DA TELA
Objetivo: explicar para que a tela serve.

[Imagem da tela com marcações 1, 2, 3...]

1. Campo/área X: função.
2. Botão Y: função.
3. Lista Z: função.

Como usar:
1. Faça isso.
2. Depois isso.
3. Finalize aqui.

Atenção:
Observação importante da tela.
```

## Ordem sugerida do manual ilustrado

### 1. Capa
**Conteúdo sugerido:**
- Logo do CAIGE;
- título: **Manual Ilustrado do Usuário — CAIGE**;
- subtítulo opcional: **Versão 1**.

### 2. Tela de Login
**Objetivo:** mostrar como entrar no sistema.

**Capturar:**
- logo;
- campos de e-mail e senha;
- botão **Entrar**.

**Legenda sugerida:**
1. Informe seu e-mail.
2. Informe sua senha.
3. Clique em **Entrar**.

### 3. Estrutura geral do sistema
**Objetivo:** explicar o shell principal.

**Capturar:**
- sidebar;
- cabeçalho superior;
- avatar/menu do usuário;
- área principal da página.

**Legenda sugerida:**
1. Menu lateral de navegação.
2. Cabeçalho da página.
3. Avatar e opções do usuário.
4. Área de conteúdo.

### 4. Painel
**Objetivo:** apresentar a visão geral do sistema.

**Destacar:**
- cards/indicadores principais;
- área central do conteúdo.

### 5. Movimentações
**Objetivo:** explicar a consulta de registros e histórico.

**Destacar:**
- filtros, se existirem;
- lista/tabela;
- botões de exportação, se disponíveis.

### 6. Lista de Pacientes
**Objetivo:** ensinar a localizar pacientes.

**Destacar:**
- pesquisa;
- filtros;
- tabela/lista;
- botão de visualizar;
- botão de novo cadastro.

### 7. Cadastro de Paciente
**Objetivo:** explicar como cadastrar um paciente.

**Destacar:**
- dados pessoais;
- responsável;
- endereço;
- dados clínicos;
- botão salvar.

### 8. Visualizar Paciente
**Objetivo:** mostrar o perfil do paciente.

**Destacar:**
- avatar/nome;
- resumo clínico;
- observações;
- atividades recentes;
- responsável/endereço;
- botão **Ver prontuário**;
- menu de ações.

### 9. Prontuário do Paciente
**Objetivo:** mostrar como consultar e lançar registros clínicos.

**Destacar:**
- cabeçalho do prontuário;
- blocos de conteúdo;
- campos/perguntas;
- botões de salvar/imprimir/voltar, quando existirem.

### 10. Gestão de Prontuários
**Objetivo:** explicar a manutenção dos modelos de prontuário.

**Subtelas sugeridas:**
- **Prontuários Cadastrados**;
- **Cadastro de Perguntas**.

### 11. Frequência
**Objetivo:** explicar registro e consulta de presença.

**Destacar:**
- seleção de curso;
- seleção de atividade;
- pesquisa/seleção de pacientes;
- lista de presença;
- geração de relatório;
- exportação/impressão.

### 12. Painel de Gerenciamento
**Objetivo:** explicar a área administrativa.

**Destacar:**
- acesso a usuários;
- auditoria;
- demais itens disponíveis ao supervisor.

### 13. Usuários
**Objetivo:** mostrar cadastro/listagem de usuários.

**Destacar:**
- filtros;
- tabela;
- novo usuário;
- edição;
- exportações.

### 14. Auditoria
**Objetivo:** mostrar onde consultar movimentações administrativas.

**Destacar:**
- filtros;
- tabela/listagem;
- exportação em PDF/Excel.

### 15. Menu do Usuário / Logout
**Objetivo:** explicar como sair do sistema e acessar opções pessoais.

**Destacar:**
- avatar;
- menu suspenso;
- opção de sair.

## Recomendações visuais
- usar prints reais do sistema já validado;
- manter bordas e sombras discretas;
- destacar áreas com círculos numerados;
- utilizar a paleta institucional do CAIGE;
- evitar excesso de texto dentro da imagem;
- usar legenda fora da imagem para facilitar leitura.

## Recomendação de tamanho do conteúdo
- **1 tela por página**, quando possível;
- em telas muito extensas, dividir em **parte superior** e **parte inferior**;
- manter textos curtos e objetivos.

## Sugestão de páginas finais
### Boas práticas
- preencher dados com atenção;
- conferir antes de salvar;
- respeitar perfil/permissões;
- realizar logout ao encerrar.

### Dúvidas frequentes
- não consigo acessar;
- não encontro o paciente;
- não vejo determinado botão;
- relatório não saiu como esperado.

- **Manual em PDF ilustrado**;
- **slides de treinamento**;
- **imagens individuais por tela** para WhatsApp, apresentação ou treinamento rápido.
